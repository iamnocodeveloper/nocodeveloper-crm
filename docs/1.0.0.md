# Nocodeveloper CRM 1.0.0

**Fecha:** 2026-10-22  
**Base:** core open source + experiencia móvil propia  
**Repo:** `iamnocodeveloper/nocodeveloper-crm`

## Qué es esta release

La primera versión pública de Nocodeveloper CRM: core open source con identidad
propia y la experiencia móvil/PWA integrada. No es una copia del build privado
de clientes: es el core comunitario más la capa móvil genérica.

## Identidad

- Nombre por defecto: **Nocodeveloper CRM**.
- Paleta: obsidiana `#070806` / `#1E241B`, lima `#C6F24E` (acento brillante en
  oscuro y barra), lima profundo `#77912F` en tema claro.
- Tipografía: **Space Grotesk** (UI), **Fraunces** (serif editorial),
  **JetBrains Mono** (etiquetas).
- Login de dos paneles: historia de marca a la izquierda, formulario a la
  derecha; en móvil, marca compacta + formulario.
- Iconos PWA 192/512/maskable y Apple touch con la “N” obsidiana/lima.
- README con hero SVG y tira de features (CSS dentro del SVG, porque GitHub
  sanea el CSS inline de Markdown).

## Móvil + PWA

- Barra inferior: Bandeja, Pipeline, Contactos, Citas (o Agente) y Más.
- Contador de no leídos compartido entre el lateral y la barra inferior.
- Cajón lateral con cierre al navegar/Escape y `safe-area`.
- Bandeja maestro-detalle; el panel de detalles se adapta a cajón.
- Compositor con hoja **+** para archivo, ubicación y contacto.
- Diálogos como hojas inferiores en el teléfono.
- Manifest, service worker, página `/offline` y registro con reintento.
- Ajustes con pestañas desplazables; Agente sin desbordes horizontales.

## Core conservado

- Bandeja de WhatsApp en tiempo real, plantillas y ventana de 24 h.
- Pipeline, contactos, importación CSV, ficha y notas.
- Agente con perfil, conocimiento y API `/api/bot/*`.
- Laboratorio con clientes simulados y juez.
- Agenda, atribución/CAPI y canales opcionales.
- White-label por organización.

## Fuera de esta release pública

- Bloqueo avanzado de IA, catálogo, ventas y automatizaciones de operación de
  clientes.
- Los fixes de WAHA específicos del build privado.
- Las capturas y datos de instancias de clientes.

## Actualizar

Es la primera release pública. Para una instalación nueva:

```bash
git clone https://github.com/iamnocodeveloper/nocodeveloper-crm.git
cd nocodeveloper-crm
cp .env.example .env
docker compose up -d --build
```

Para desarrollo, sigue `docs/getting-started.md`.

## Limitaciones conocidas

- GitHub no permite CSS inline en README: el diseño va en los SVG de
  `docs/assets/readme/`.
- La bandeja móvil del core no incluye la hoja de acciones premium del build
  privado; conserva las acciones que existen en el core.
- El compositor público ofrece los adjuntos que soporta el core; no incluye
  notas de voz ni respuestas rápidas si no están en el upstream.
- La imagen GHCR se publica al crear el tag `v1.0.0`; mientras tanto, usa
  `docker compose up -d --build`.
